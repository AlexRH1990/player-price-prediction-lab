# ⚽ Player Price Prediction Lab (AWS S3 + Machine Learning)

Pipeline de Data Science de punta a punta para la predicción del valor de mercado de futbolistas utilizando infraestructura en la nube (AWS S3) y modelos de Regresión.

## 🏗️ Arquitectura de Datos
- **Ingesta:** Kaggle API ➔ AWS S3 (`player-price-prediction-lab`)
- **Procesamiento:** Python (`boto3`, `pandas`, `io.BytesIO`)
- **Modelado:** Scikit-Learn (Regresión Lineal)
